# Enkelband-checker

Opdracht voor de gastles "De ICT-wereld achter de agent op straat".
Leerlingen bouwen in hun browser (via [stlite](https://github.com/whitphx/stlite)) een Streamlit-app
die op basis van verzonnen enkelbanddata uitzoekt welke personen met elkaar afspreken.

- `index.html`: de startpagina voor leerlingen (GitHub Pages)
- `data/enkelbanden_almelo.csv`: verzonnen locatiedata (8 personen, één weekend, Almelo)
- `code/`: de startbestanden van route A, B en C

Alle personen en locaties in de data zijn verzonnen.
